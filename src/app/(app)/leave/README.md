# /leave

**Purpose:** Apply for leave, see balances, approve team requests.

**Access:** Everyone applies. Managers approve/reject their team. Super Admin approves anyone. Pending requests can be cancelled by the requester.

**Features:** balance cards per leave type (quota − approved days this year), half day for single-day requests, working-day count excludes weekly off, tabs: My requests / Awaiting approval / Team history.

**Effect elsewhere:** approved leave is excluded from working days in attendance % and shows "On leave" in Team Tracker.

**Customize:** Settings → Leave (types and yearly quotas).

**Data:** `leave_requests`.
