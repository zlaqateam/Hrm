# /tasks

**Purpose:** Simple kanban (To do → In progress → Review → Done) with priority, due dates and optional link to a Key Result.

**Access:** Everyone can create tasks. Visible: assigned to you, created by you, your department's tasks, or (managers) your team's. Move: assignee, creator, their managers, Super Admin. Delete: creator or Super Admin.

**Feeds:** Task completion % → performance score (Tasks weight). Overdue dates turn red.

**Data:** `tasks` (+ `key_results`, `objectives` for linking).

**Toggle:** Settings → Modules → Tasks.

**Migration notes:** Drag-and-drop can be added later (e.g. dnd-kit) without data changes.
