# /employees/[id] — Employee profile

**Purpose:** One-page view of a person: contact, role, manager, score ring, attendance/punctuality/OKR/task stats (30 or 90 days), worked-hours chart, current OKRs, attendance log with selfies and correction notes.

**Access:** Super Admin, or a Manager who manages this person (`canManage`).

**Data:** `useWorkspace(90)`.

**Use it for:** 1:1s, probation reviews, quarterly reviews.
